# Diagnose Without Logging

## Idea

원두 등록, 장비 등록, 세션 생성 없이도 바로 샷을 진단할 수 있는 모드다.

필수 입력은 빠른 진단의 최소값만 사용한다.

- 맛 설명
- 도징량
- 추출량
- 추출 시간

## Why It Matters

경쟁 앱의 불편사항 중 하나는 기록을 시작하기 위한 준비가 무겁다는 점이다. 에스프레소 코치의 첫 경험은 "기록 앱"이 아니라 "지금 이 샷을 어떻게 고칠지 알려주는 도구"여야 한다.

## Possible Flow

1. 첫 화면에서 "바로 진단"을 누른다.
2. 최소 입력 4개를 넣는다.
3. 앱이 임시 세션 컨텍스트로 진단 결과를 만든다.
4. 결과 화면에서 사용자는 이 샷을 저장하거나 버릴 수 있다.
5. 저장 시 기본 세션 또는 새 원두 세션에 연결한다.

## MVP Boundary

Allowed:
- 세션 없이 임시 진단
- 진단 후 저장 여부 선택
- 배전 범위는 `unknown`으로 처리하거나 선택값으로 받기

Not allowed:
- 진단 전에 원두/장비 등록을 강제
- 로그인 또는 동기화 설정을 요구
- 임시 진단과 저장된 기록의 결과 구조를 다르게 만들기

## Data Implication

임시 진단도 저장된 샷과 같은 진단 파이프라인을 사용해야 한다. 차이는 `ShotRecord`로 persist되었는지 여부뿐이어야 한다.

## Promotion Criteria

이 아이디어를 planning 문서로 승격하려면 아래가 필요하다.

- 임시 진단 객체와 저장 샷 객체의 관계
- 진단 후 저장 UX
- 기본 세션 생성 규칙
- 저장하지 않은 진단 결과의 보존 여부
