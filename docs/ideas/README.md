# Ideas

에스프레소 코치의 제품 아이디어, 실험 후보, 나중에 검토할 기능을 모아두는 공간이다.

## Usage

- 확정된 기획은 `docs/planning/`에 둔다.
- 아직 검토 중인 아이디어는 이 디렉토리에 둔다.
- MVP 범위에 넣을지 불명확한 내용은 먼저 아이디어로 기록한 뒤 planning 문서로 승격한다.

## Idea List

- [Natural Language Processing](natural-language-processing.md): 맛 자연어 입력을 내부 진단 태그와 패턴으로 바꾸는 아이디어
- [Bean Link Info Helper](bean-link-info-helper.md): 원두 구매 링크를 받아 세션 정보 입력을 돕는 아이디어
- [Cause Candidate Ranking](cause-candidate-ranking.md): 진단 원인 후보를 가능성 순서로 보여주는 아이디어
- [Next Shot Experiment Card](next-shot-experiment-card.md): 다음 샷에서 바꿀 변수, 유지할 변수, 기대 변화를 카드로 정리하는 아이디어
- [Keep Fixed Variables](keep-fixed-variables.md): 추천 결과에서 바꾸지 말아야 할 변수를 명시하는 아이디어
- [Diagnose Without Logging](diagnose-without-logging.md): 원두/장비 등록 없이 최소 입력으로 바로 진단하는 아이디어
- [Bean Session Auto Draft](bean-session-auto-draft.md): 링크나 텍스트에서 원두 세션 초안을 만드는 아이디어
- [Roast Based Taste Baseline](roast-based-taste-baseline.md): 배전 범위별 기대 맛 기준으로 맛 표현을 해석하는 아이디어
- [Is This Taste A Problem](is-this-taste-a-problem.md): 맛 표현이 원두 특성인지 추출 문제인지 구분하는 아이디어
- [Failure Shot Friendly Logging](failure-shot-friendly-logging.md): 실패 샷을 실험 과정으로 부담 없이 기록하게 하는 아이디어
- [Previous Shot Delta Analysis](previous-shot-delta-analysis.md): 이전 샷 대비 변수 변화와 맛 변화를 분석하는 아이디어
- [Taste Tag Suggestions From User Language](taste-tag-suggestions-from-user-language.md): 사용자 말투에서 맛 태그를 추천하고 수정 가능하게 하는 아이디어
- [Beginner Advanced Mode Split](beginner-advanced-mode-split.md): 초보/고급 모드를 분리해 입력 부담을 낮추는 아이디어
- [Stop Changing Guidance](stop-changing-guidance.md): 계속 바꾸기보다 멈추고 준비 과정을 확인하게 하는 아이디어
