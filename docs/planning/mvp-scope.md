# MVP Scope

## Included

### Session

- 원두별 다이얼링 세션 생성
- 배전 범위를 세션 선택값으로 기록
- 세션 안에서 여러 샷 기록
- 직전 샷과 현재 샷 비교

### Quick Diagnosis

- 자연어 맛 설명 입력
- 도징량 입력
- 추출량 입력
- 추출 시간 입력

### Optional Basic Observations

- 배전 범위
- 분쇄도 메모
- 채널링 관찰
- 퍽 상태
- 탬핑/레벨링 문제

### Natural Language Processing

- 규칙 기반 맛 표현 매핑
- 애매한 문장에 대한 LLM 보정
- 내부 구조화 태그 생성

### Basic Recommendation Variables

- 분쇄도
- 도징량
- 추출량
- 탬핑 일관성
- 레벨링/분배
- 채널링 의심
- 퍽 준비 문제

### Diagnostic and Context Signals

- 배전 범위
- 추출 시간
- 추출 비율
- 직전 샷 대비 변경값

### Advanced Mode

고급 모드는 사용자가 켤 때만 노출한다.

- 머신 압력/온도 세부 조절
- 원두 디개싱 기간 최적화
- 물 조성
- 바스켓/샤워스크린/그라인더 버 성능 분석
- 프리인퓨전 세부 프로파일링

## Deferred Unless Needed

- 커뮤니티
- 레시피 공유
- 사용자 간 랭킹
- 쇼핑몰/원두 추천
- 장기간 통계 대시보드
- 자동 장비 연동
- 모바일 앱 네이티브 기능

## Explicit MVP Guardrails

- 첫 화면은 빠른 진단 중심이어야 한다.
- 고급 입력은 기본 흐름을 막으면 안 된다.
- 추천 로직은 LLM이 임의로 결정하면 안 된다.
- 배전 범위만으로 추출 문제를 단정하지 않는다.
- 채널링 가능성이 있을 때는 레시피 변수만으로 단정하지 않는다.
- 사용자가 한 번에 여러 변수를 바꾸도록 유도하지 않는다.
